# Мини-графический редактор

## 1. Название и описание задачи

Программа представляет собой простой графический редактор, который позволяет создавать и редактировать геометрические фигуры: круги, прямоугольники и треугольники.

**Что делает программа:**
- Создает фигуры с заданными параметрами (цвет, размер, положение)
- Вычисляет площадь и периметр каждой фигуры
- Отображает информацию о всех созданных фигурах
- Демонстрирует принципы объектно-ориентированного программирования

**Решаемая задача:** Изучение основ ООП на примере графического редактора.

---

## 2. Архитектура проекта

Проект построен на трех основных принципах ООП:

### Инкапсуляция
- **Скрытые данные (приватные атрибуты)**: 
  - `__color` — цвет фигуры
  - `__x`, `__y` — координаты положения
  - Внутренние расчетные параметры (радиус, стороны и т.д.)
- **Публичные методы**: 
  - `get_color()`, `set_color()` — для работы с цветом
  - `get_area()` — вычисление площади
  - `get_perimeter()` — вычисление периметра
  - `move(dx, dy)` — перемещение фигуры
  - `info()` — вывод информации о фигуре
