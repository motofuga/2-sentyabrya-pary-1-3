# Мини-графический редактор

## 1. Название и описание задачи

Программа представляет собой простой графический редактор, который позволяет создавать и редактировать геометрические фигуры: круги, прямоугольники и треугольники.

**Что делает программа:**
- Создает фигуры с заданными параметрами (цвет, размер, положение)
- Вычисляет площадь и периметр каждой фигуры
- Отображает информацию о всех созданных фигурах
- Демонстрирует принципы объектно-ориентированного программирования

**Решаемая задача:** Изучение основ ООП на примере графического редактора.

---

## 2. Архитектура проекта

Проект построен на трех основных принципах ООП:

### Инкапсуляция
- **Скрытые данные (приватные атрибуты)**: 
  - `__color` — цвет фигуры
  - `__x`, `__y` — координаты положения
  - Внутренние расчетные параметры (радиус, стороны и т.д.)
- **Публичные методы**: 
  - `get_color()`, `set_color()` — для работы с цветом
  - `get_area()` — вычисление площади
  - `get_perimeter()` — вычисление периметра
  - `move(dx, dy)` — перемещение фигуры
  - `info()` — вывод информации о фигуре

### Наследование
Shape (Базовый класс)
/ |
Circle Rectangle Triangle

text
- **Shape** — абстрактный базовый класс с общими методами
- **Circle**, **Rectangle**, **Triangle** — дочерние классы с реализацией специфических расчетов

### Полиморфизм
Все фигуры используют единый интерфейс:
- Единый метод `get_area()` возвращает площадь для любой фигуры
- Единый метод `get_perimeter()` возвращает периметр
- Единый метод `info()` выводит информацию, но каждая фигура форматирует вывод по-своему

## 3. Пример использования

```python
# Создание графического редактора
editor = GraphicEditor()

# Добавление фигур
circle = Circle(radius=5, color="red", x=0, y=0)
rectangle = Rectangle(width=4, height=6, color="blue", x=2, y=3)
triangle = Triangle(side1=3, side2=4, side3=5, color="green", x=1, y=1)

editor.add_shape(circle)
editor.add_shape(rectangle)
editor.add_shape(triangle)

# Вывод информации о всех фигурах
editor.show_all_shapes()

# Перемещение фигуры
circle.move(10, 5)

# Изменение цвета
rectangle.set_color("yellow")

# Вывод площади конкретной фигуры
print(f"Площадь круга: {circle.get_area():.2f}")
